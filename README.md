# QUANT BRAIN

Это простой сайт на React и Vite.

Установить Node.js:

[nodejs.org](https://nodejs.org/)

Лучше поставить версию LTS.

## Как запустить

Установить зависимости:

```bash
npm install
```

Запустить сайт:

```bash
npm run dev
```

После запуска открой адрес, который появится в терминале.
